Через каждый из резисторов бежит один и тот же ток
по закону Ома:
R=U/I
По закому Кихргофа общее напряжение будет равно сумме падения напряжения на каждом из резисторов:
U=U_1+U_2
Подставим в 1 уравнение
R=U_1/I + U_2/I
А из закона Ома R=U/I => R=R_1+R_2
![[Pasted image 20260102130814.png]]по закону кихргофа
